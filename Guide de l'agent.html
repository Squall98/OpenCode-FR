Utilisation

  1. Double-clic sur Lancer l'agent.cmd. Le moteur IA locale démarre s'il le faut, puis le menu de tes conversations s'affiche : Entrée = reprendre la dernière, un numéro = reprendre celle-là, N = nouvelle, Q = quitter.
  2. Écris ta mission en français. Le premier message prend ~10 s de plus (chargement du modèle).
  3. Pas besoin de changer de profil : build fait tout (dev et reverse avec les 207 outils REA). Pour changer quand même de profil : Shift+Tab (pas Tab seul).
  4. Quand il veut lancer une commande, il te la montre : lis-la, puis accepte une fois, toujours, ou refuse.
  5. /exit pour quitter. Le modèle libère la VRAM après 10 min d'inactivité. Pour un titre clair dans le menu : Ctrl+R dans OpenCode.

Analyser un site web

D'abord : double-clic sur Ouvrir Chrome d'analyse.cmd, puis ouvre le site dans ce Chrome-là.

« Analyse le site ouvert dans le Chrome d'analyse : quels frameworks, quels appels d'API, et comment marche la page de connexion. »
« Je vais cliquer sur le bouton Ajouter au panier dans 10 secondes : observe ce qui part sur le réseau et explique-le. »
« Voici un fichier HAR dans projets\monsite\capture.har : liste les endpoints d'API. »

Développer

« Dans projets\scraper-prix, écris un script Python qui lit ce JSON et fait un tableau CSV, avec des tests. Lance les tests. »
« Reprends projets\monsite et écris un petit client Python pour l'API qu'on a trouvée. »

Installer un outil

« Installe l'outil https://github.com/… dans outils\ en suivant ta skill installer-outil. »

Il vérifie la source, te montre chaque commande et installe tout dans outils\<nom>\. Pour un dépôt inconnu ou douteux, passe plutôt par Claude.

Astuce : des missions courtes et précises marchent bien mieux qu'un gros projet flou. Découpe : « analyse », puis « écris le client », puis « ajoute les tests ».

REA a 207 outils (~3,3 Mo de descriptions) : trop pour les charger d'un coup. OpenCode les passe en « Code Mode » : l'agent les appelle à la demande via execute → tools.rea.<outil>. Ne marchent pas sous Windows : récupération de sources (Linux), WebAssembly (WABT absent).
