Lexique OpenCode

Les mots et raccourcis de l'agent en version terminal (v2.0.29), traduits en français.

Le terminal est maintenant en français grâce au patch de D:\IA LOCAL\_maintenance\OpenCode-francais. Après une mise à jour d'OpenCode, relance Patcher en français.cmd. Les raccourcis restent les mêmes.
Touche « leader » = Ctrl+X. Quand tu vois <leader> N, ça veut dire : appuie sur Ctrl+X, lâche, puis appuie sur N.

Ctrl+D efface un caractère dans la zone de texte, mais supprime la conversation dans la liste des conversations, et interrompt un sous-agent quand il est sélectionné. Ctrl+F avance le curseur quand tu écris, mais épingle une conversation dans la liste.
SessionConversation

Un échange avec l'agent, gardé dans l'historique.

PromptMessage / consigne

Ce que tu écris à l'agent. La « prompt box » est la zone de saisie en bas.

AgentAgent

Un rôle avec ses consignes et ses outils. Chez toi, l'agent principal est equipe.

SubagentSous-agent

Un agent appelé par l'agent principal pour une sous-tâche (chez toi : analyste, codeur, debogueur, testeur). Il travaille dans sa propre conversation « enfant ».

Child session / Parent sessionConversation enfant / parente

La conversation d'un sous-agent (enfant) et celle qui l'a lancé (parente).

BackgroundArrière-plan

Un outil ou un sous-agent qui continue de tourner sans te bloquer. Ctrl+B y envoie ce qui bloque.

Compaction / CompactCompactage / Compacter

Résumer automatiquement le début de la conversation quand la mémoire du modèle (le contexte) est presque pleine. Rien n'est supprimé de l'historique.

ContextContexte

Tout ce que le modèle « voit » à un moment donné : consignes, messages, fichiers lus. Il a une taille limite.

TokensJetons

Les morceaux de texte que compte le modèle (≈ ¾ d'un mot). La taille du contexte se mesure en jetons.

Tab / TabsOnglet / Onglets

La barre qui permet de garder plusieurs conversations ouvertes et de passer de l'une à l'autre.

SidebarBarre latérale

Le panneau sur le côté (fichiers modifiés, infos). <leader> B l'affiche ou le cache.

Command palettePalette de commandes

La liste de toutes les actions, ouverte avec Ctrl+P.

Leader keyTouche leader

Ctrl+X : la touche qu'on presse avant une lettre pour lancer un raccourci.

InterruptInterrompre

Arrêter l'agent en plein travail (Échap).

Queue / Queued promptFile d'attente / Message en attente

Un message écrit pendant que l'agent travaille, envoyé quand il a fini. <leader> Q pour les gérer.

SteerOrienter

Envoyer ton message tout de suite pour corriger le travail en cours, au lieu de le mettre en attente.

AsideQuestion à part

Poser une petite question sans déranger le travail en cours.

StashMettre de côté

Garder un brouillon de message pour plus tard, puis le reprendre.

PermissionAutorisation

L'agent te demande s'il peut faire une action (lancer une commande, modifier un fichier). Allow = autoriser, Deny = refuser, Always = toujours.

Tool / Tool callOutil / Appel d'outil

Une action de l'agent : lire un fichier, chercher, lancer une commande, appeler un MCP…

ShellTerminal / commande

Une commande lancée par l'agent. Les commandes en cours se choisissent avec ↑ ↓ et s'arrêtent avec Ctrl+D.

ThinkingRéflexion

Le raisonnement du modèle avant sa réponse, qu'on peut afficher ou masquer.

Transcript / TimelineFil / Chronologie

Le déroulé des messages et des actions de la conversation (<leader> G pour la chronologie).

Undo / RedoAnnuler / Rétablir

Sur un message (<leader> U / R), c'est annuler le dernier échange et ce qu'il a modifié.

ForkBifurquer / Dupliquer

Repartir d'un message pour créer une nouvelle conversation à partir de là.

Diff / HunkDifférences / Bloc de modifications

L'affichage de ce qui a changé dans les fichiers (/diff). Un « hunk » est un bloc de lignes modifiées.

Split / Unified viewVue côte à côte / Vue unifiée

Deux façons d'afficher les différences (V dans le visualiseur).

Last turnDernier tour

La dernière réponse de l'agent et tout ce qu'elle a fait.

WorktreeCopie de travail (git)

Un dossier séparé du même dépôt git, pour travailler sans toucher à l'original.

ProviderFournisseur

Qui fournit le modèle. Chez toi : runpod (le GPU loué) et l'IA locale.

VariantVariante

Une version d'un modèle avec d'autres réglages (ex. plus ou moins de réflexion), changée avec Ctrl+T.

FavoriteFavori

Un modèle marqué en favori (Ctrl+F dans la liste des modèles).

MCP serverServeur MCP

Un module qui donne des outils en plus à l'agent (REA, Playwright, Perplexity…).

SkillCompétence

Une fiche de méthode que l'agent peut charger pour une tâche précise.

PluginExtension

Un ajout au logiciel lui-même (pas à l'agent).

PinÉpingler

Garder une conversation en haut de la liste.

UnreadNon lu

Un onglet où l'agent a répondu sans que tu l'aies regardé.

StatusÉtat

L'état du serveur, des MCP et du modèle (<leader> S).

Which-keyAide aux raccourcis

Le panneau qui montre les touches possibles (Ctrl+Alt+K).

HighlightsNouveautés

Les nouveautés affichées une fois après une mise à jour (/highlights pour les revoir).

Pair / Pairing linkAppairer / Lien de connexion

Le lien à usage unique qui connecte un navigateur au serveur (le lanceur web s'en occupe).

Done / Error / QuestionTerminé / Erreur / Question

Les alertes (son, notification) quand l'agent a fini, plante ou attend ta réponse.

La version terminal n'existe qu'en anglais. La version web, elle, est traduite en français. Elle utilise les mêmes réglages, les mêmes agents et le même historique.

Lancer la version web

  1. Double-clique sur D:\IA LOCAL\Lancer l'agent (web).cmd.
  2. Une petite fenêtre « OpenCode web » s'ouvre, réduite dans la barre des tâches : c'est le serveur. Ton navigateur s'ouvre ensuite tout seul, déjà connecté.
  3. Pour arrêter : ferme la fenêtre « OpenCode web ».

Le serveur n'écoute que sur ton PC (127.0.0.1:4096). Un nouveau mot de passe est tiré au hasard à chaque lancement. Si tu relances alors que le serveur tourne encore, la page se rouvre simplement.

Mettre l'interface en français

Elle suit la langue de ton navigateur, donc elle est normalement déjà en français. Sinon :

  1. En bas à gauche, clique sur Settings (Paramètres).
  2. Preferences → General → Language (Préférences → Général → Langue).
  3. Choisis Français.
Dans les mêmes Préférences, l'option « Agents personnalisés : afficher le sélecteur d'agent dans la zone de saisie » permet de choisir equipe ou un autre agent directement sous la zone de texte.
